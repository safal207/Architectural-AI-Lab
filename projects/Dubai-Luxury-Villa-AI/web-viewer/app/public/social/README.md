# Link preview cover

`desert-distilled-v1.png` is the branded Open Graph and large-image social card
for the public residence portfolio. Dimensions: 1730 × 909; format: PNG.

Created with the built-in imagegen tool using `../editorial/residence-1600.webp`
as the villa reference. This is a marketing composition, not model-validation
evidence. The original Blender render, editorial images and GLB are unchanged.

Prompt: create a wide architectural editorial cover with an ivory text panel,
charcoal serif title “Desert, distilled.”, “ARCHITECTURAL AI LAB”,
“Architecture · Interiors · 3D”, and “DUBAI RESIDENCE / 001”; place the supplied
pool-side villa render alongside it, preserving its recognizable architecture,
glazing, terrace and pool. Use no contact details, buttons or watermark.

The static metadata in `../../index.html` uses absolute public URLs so link
preview crawlers can read the title, description and image without JavaScript.
Use a new image filename when replacing the cover to avoid stale image caches.
