# Material sources

Selected 1K JPEG maps: Diffuse, OpenGL normal and Roughness. Downloaded from the official Poly Haven API on 2026-09-29, served locally without a third-party runtime request.

- Wood Floor Deck by Dimitrios Savva: https://polyhaven.com/a/wood_floor_deck
- Asphalt 02 by Rob Tuytel: https://polyhaven.com/a/asphalt_02

Both assets are CC0: https://polyhaven.com/license
CC0 text: https://creativecommons.org/publicdomain/zero/1.0/

The original maps are unchanged. UV scale, material colour and normal strength are viewer settings.
