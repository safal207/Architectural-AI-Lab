# Editorial images

These WebP files are responsive derivatives of native Blender renders in this
repository, not photographs or generated substitutes for the interactive model.

- `residence-{800,1600}.webp`: `../../../../renders/villa-v0.4-pool-context-v4.png`.
  This is the current pool-context exterior study.
- `interior-{800,1600}.webp`: `../../../../renders/villa-v0.4-interior2.png`.
  This is the earlier interior concept study, identified as such in the gallery.

Each source is 1600 × 900. Derivatives retain its proportions and use WebP
quality 88. The interactive viewer continues to use the unchanged canonical
`villa.glb`; the gallery is a presentation of project studies.
