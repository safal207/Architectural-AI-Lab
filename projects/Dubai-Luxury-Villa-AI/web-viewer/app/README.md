# Dubai Luxury Villa Viewer App

Prototype structure for an interactive digital twin viewer.

## Planned stack

- React
- Three.js
- React Three Fiber (optional)
- GLTFLoader

## MVP features

- Load villa GLB model
- Orbit camera controls
- Select rooms
- Display room metadata
- Camera presets

## Future features

- AI real estate assistant
- Day/night lighting
- Material variants
- Investor presentation mode
