# Dubai Luxury Villa Web Viewer

Interactive browser presentation concept for a digital twin.

## Goal

Transform a 3D villa model into an interactive real-estate experience.

## Planned stack

- React
- Three.js
- GLTFLoader
- WebGL

## Features

- 3D navigation
- room selection
- room information
- camera presets
- material variants
- day/night presentation

## Input

- villa.glb
- rooms.json

## Output

Interactive digital twin prototype.
