# Digital Twin Quality Checklist

## Geometry

- room structure is defined
- scale assumptions are documented
- major zones are represented

## Data consistency

- room names match metadata
- areas are documented
- unknown values are marked

## Export

- GLB opens successfully
- materials are reviewed
- version consistency is checked

## Presentation

- renders match the same model version
- viewer labels match rooms
- limitations are documented

## Scope

This repository demonstrates AI-assisted architectural visualization workflows. It is not construction-ready documentation.
