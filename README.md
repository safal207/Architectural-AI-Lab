# Architectural-AI-Lab

AI-assisted architectural visualization portfolio: native Blender generation, gated visual development, interactive 3D viewers, and reproducible QA evidence.

## Featured project — Dubai Luxury Villa AI

**Live interactive prototype:** https://safal207.github.io/Architectural-AI-Lab/
